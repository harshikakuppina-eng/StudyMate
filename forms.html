📝 HTML Forms

Learn how to collect information from users using HTML forms.

1. What is an HTML Form?

A form is used to collect information from the user.

Examples: Login forms, registration forms, feedback forms and contact forms.

2. Form Tag

The <form> tag is used to create a form. 

<form>

    Form elements go here.

</form>

3. Input Element

The <input> element is used to take information from the user. 

<input type="text">

4. Common Input Types

  • text → Text input
  • email → Email address
  • password → Password
  • number → Numbers
  • date → Date
  • checkbox → Multiple choices
  • radio → One choice
  • submit → Submit button

5. Label

The <label> tag describes an input field. 

<label>Name:</label>

<input type="text">

6. Select & Option

The <select> element creates a dropdown list. 

<select>

    <option>Python</option>
    <option>HTML</option>
    <option>CSS</option>

</select>

7. Textarea

Textarea is used when the user needs to enter multiple lines of text. 

<textarea>
Write your message here...
</textarea>

🔐 Cybersecurity Example

Login and registration pages use HTML forms to collect username, email and password.

Later, JavaScript and Flask can process this information.

⭐ Important Points

  • <form> → Creates a form
  • <label> → Describes an input
  • <input> → Takes user input
  • <select> → Creates dropdown
  • <textarea> → Multiple-line input
  • <button> → Creates a button
