📌 How the Project Works

  1. Enter student's name.
  2. Enter marks for 3 subjects.
  3. Calculate total marks.
  4. Calculate average.
  5. Find the grade.
  6. Display Pass or Fail.

💡 Grade System

  • 90 and above → A
  • 80–89 → B
  • 70–79 → C
  • 60–69 → D
  • Below 60 → F
