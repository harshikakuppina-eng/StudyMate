Conditions & Loops 🔄

Learn how JavaScript makes decisions and repeats tasks.

1. What are Conditions?

Conditions are used to make decisions in a program. JavaScript commonly uses if, else if, and else.

2. if Statement

The if statement runs code when a condition is true. 


let age = 18;

if (age >= 18) {
    console.log("You are eligible to vote.");
}

3. if...else

else runs when the if condition is false. 


let age = 16;

if (age >= 18) {
    console.log("Eligible");
} else {
    console.log("Not eligible");
}

4. else if

We use else if when we have multiple conditions. 


let marks = 75;

if (marks >= 90) {
    console.log("Grade A");
} else if (marks >= 60) {
    console.log("Grade B");
} else {
    console.log("Grade C");
}

5. What is a Loop?

A loop is used to repeat a block of code multiple times.

6. for Loop

A for loop is commonly used when we know how many times we want to repeat something. 


for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Output:


1
2
3
4
5

7. while Loop

A while loop continues as long as the condition is true. 


let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

8. Real-Life Example 💡

Imagine checking students' marks one by one. A condition decides their grade, while a loop can repeat the process for many students.

Quick Summary 🧠

  • if → checks a condition
  • else → runs when the condition is false
  • else if → checks another condition
  • for → repeats code a fixed number of times
  • while → repeats while a condition is true
