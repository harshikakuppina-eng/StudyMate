🚪 Ports & Protocols

Learn what network ports and protocols are and how they help applications communicate.

🚪 What is a Port?

A port is a logical number used to identify a particular service or application endpoint on a device.

Port numbers range from 0 to 65535.

📡 What is a Protocol?

A protocol is a set of rules that defines how devices communicate and exchange data.

Examples include HTTP, HTTPS, DNS and TCP.

📋 Common Ports

🌐 HTTP → Port 80

🔒 HTTPS → Port 443

📧 SMTP → Port 25

📖 DNS → Port 53

🔐 SSH → Port 22

🔐 TCP and UDP

TCP is connection-oriented and provides reliable delivery.

UDP is connectionless and generally has lower overhead.

💻 Simple Example

When you access a website using HTTPS, your browser communicates with the web service using HTTPS, normally through port 443.

🛡️ Importance in Cybersecurity

Security professionals need to understand ports and protocols when analyzing network communication and configuring security controls.

📝 Key Points

• Port = Logical communication endpoint

• Port range = 0–65535

• Protocol = Communication rules

• HTTPS commonly uses port 443

• SSH commonly uses port 22
