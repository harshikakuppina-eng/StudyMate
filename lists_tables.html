📋 Lists & Tables

Learn how to create lists and tables in HTML.

1. Unordered List

An unordered list displays items using bullet points. 

<ul>
    <li>Python</li>
    <li>HTML</li>
    <li>CSS</li>
</ul>

Output:

  • Python
  • HTML
  • CSS

2. Ordered List

An ordered list displays items with numbers. 

<ol>
    <li>Login</li>
    <li>Scan</li>
    <li>Analyze</li>
</ol>

Output:

  1. Login
  2. Scan
  3. Analyze

3. Description List

A description list is used for terms and their descriptions. 

<dl>

    <dt>HTML</dt>
    <dd>HyperText Markup Language</dd>

    <dt>CSS</dt>
    <dd>Cascading Style Sheets</dd>

</dl>

Output:

HTML
HyperText Markup Language
CSS
Cascading Style Sheets

4. HTML Tables

Tables are used to display information in rows and columns. 

<table>

    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>

    <tr>
        <td>Harshika</td>
        <td>Cybersecurity</td>
    </tr>

</table>

5. Table Example

Name Course Semester
Harshika Cybersecurity 3rd
Rahul Computer Science 3rd

⭐ Important Points

  • <ul> → Unordered list
  • <ol> → Ordered list
  • <li> → List item
  • <table> → Creates a table
  • <tr> → Table row
  • <th> → Table heading
  • <td> → Table data
