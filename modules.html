Modules & Packages 📦

Learn how to reuse Python code using modules and packages.

1. What is a Module?

A module is a Python file containing code such as functions, variables and classes.

Modules help us reuse code instead of writing the same code again and again.

2. import

We use import to use a module in our Python program. 

import math

print(math.sqrt(25))

Output: 

5.0

3. from ... import

We can import a specific function from a module. 

from math import sqrt

print(sqrt(36))

Output: 

6.0

4. Common Python Modules

  • math → Mathematical operations
  • random → Generate random values
  • datetime → Work with date and time
  • os → Work with operating-system features

5. random Module

The random module is used to generate random values. 

import random

number = random.randint(1, 10)

print(number)

Every time you run the program, a different number between 1 and 10 may be generated.

6. What is a Package?

A package is a collection of related Python modules stored together.

Simple ga cheppali ante:

  • Module → One Python file
  • Package → Collection of modules

7. Cybersecurity Example 🔐

Cybersecurity programs often use Python modules for random values, hashing, networking and system tasks. 

import hashlib

text = "password123"

hashed = hashlib.sha256(
    text.encode()
).hexdigest()

print(hashed)

Here, the hashlib module is used to create a SHA-256 hash.

8. Important Points ⭐

  • Module is a Python file.
  • import is used to use a module.
  • from ... import imports specific items.
  • Package contains multiple related modules.
  • Modules help us reuse code.
