PYTHON SETS

Python Sets 🧩

Learn how to store unique values using Python Sets.

What is a Set?

A Set is a collection of unique values in Python.

A Set automatically removes duplicate values. 

numbers = {1, 2, 3, 4}

1. Duplicate Values

Sets do not allow duplicate values. 

numbers = {1, 2, 3, 3, 4}

print(numbers)

Output:

{1, 2, 3, 4}

2. Adding Values

We can use add() to add a new value. 

subjects = {"Python", "Linux"}

subjects.add("Networking")

print(subjects)

3. Removing Values

We can use remove() to remove a value. 

subjects = {"Python", "Linux", "Networking"}

subjects.remove("Linux")

print(subjects)

4. Union

union() combines two Sets. 

a = {1, 2, 3}
b = {3, 4, 5}

result = a.union(b)

print(result)

Output:

{1, 2, 3, 4, 5}

5. Intersection

intersection() finds the common values between two Sets. 

a = {1, 2, 3}
b = {2, 3, 4}

result = a.intersection(b)

print(result)

Output:

{2, 3}

6. Real-Life Example 🔐

In cybersecurity, Sets can be useful when we want to remove duplicate IP addresses. 

ip_addresses = {
    "192.168.1.10",
    "192.168.1.20",
    "192.168.1.10",
    "192.168.1.30"
}

print(ip_addresses)

The duplicate IP address will automatically be removed.

Important Points ⭐

  • Sets store unique values.
  • Duplicates are automatically removed.
  • Sets use curly brackets { }.
  • add() adds a value.
  • remove() removes a value.
  • union() combines Sets.
  • intersection() finds common values.
