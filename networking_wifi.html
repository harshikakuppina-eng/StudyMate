📶 Wi-Fi & Wireless Networks

Learn how wireless networks work and how devices communicate without physical network cables.

📡 What is Wi-Fi?

Wi-Fi is a wireless networking technology that allows devices such as laptops, smartphones and tablets to connect to a network using radio signals.

🔄 How Wi-Fi Works

A wireless router sends and receives data using radio signals.

Example:

📱 Mobile → 📶 Wi-Fi Router → 🌐 Internet

🏷️ What is SSID?

SSID stands for Service Set Identifier.

It is basically the name of a Wi-Fi network that you see when connecting your device.

Example: Home_WiFi

🔐 Wi-Fi Security

Wi-Fi networks should use strong security mechanisms to prevent unauthorized access.

Common Wi-Fi security standards include:

• WPA2

• WPA3

WPA3 is a newer security standard designed to provide stronger protection.

📶 2.4 GHz vs 5 GHz

2.4 GHz: Longer range but usually more interference.

5 GHz: Higher speeds in many situations but generally shorter range.

🛡️ Wi-Fi Security Tips

✔ Use WPA2 or WPA3

✔ Use a strong Wi-Fi password

✔ Change default router credentials

✔ Keep router firmware updated

✔ Avoid connecting to unknown networks

📝 Key Points

• Wi-Fi provides wireless network connectivity

• SSID is the Wi-Fi network name

• WPA2 and WPA3 provide Wi-Fi security

• 2.4 GHz generally provides greater range

• 5 GHz can provide higher speeds
