Python Functions 🧩

Learn how to create reusable blocks of code using Python functions.

What is a Function?

A function is a reusable block of code that performs a particular task.

Instead of writing the same code again and again, we can put it inside a function and call it whenever we need it.

1. Creating a Function 🔨

In Python, we use the def keyword to create a function. 

def greet():
    print("Hello!")

greet()

Output:

Hello!

Here, greet() is the function call.

2. Function Parameters 📦

Parameters allow us to pass information into a function. 

def greet(name):
    print("Hello", name)

greet("Harshika")

Output:

Hello Harshika

3. Multiple Parameters ➕

A function can have more than one parameter. 

def add(a, b):
    print(a + b)

add(10, 20)

Output:

30

4. return Statement 🔙

The return statement sends a result back from the function. 

def add(a, b):
    return a + b

result = add(10, 20)

print(result)

Output:

30

5. Default Parameter ⚙️

We can give a parameter a default value. 

def greet(name="Student"):
    print("Hello", name)

greet()
greet("Harshika")

Output:

Hello Student
Hello Harshika

6. Real-Life Example 🎯

Imagine you frequently need to calculate the total marks of a student.

Instead of writing the calculation every time, create a function once and reuse it. 

def total_marks(m1, m2, m3):
    return m1 + m2 + m3

total = total_marks(80, 75, 90)

print("Total:", total)

Output:

Total: 245

Why Use Functions? 🤔

Functions help us to:

  • ♻️ Reuse code
  • 📖 Make code easier to understand
  • 🛠️ Reduce repeated code
  • 🐞 Make debugging easier
  • 📦 Organize programs into smaller parts
