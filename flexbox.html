9️⃣ CSS Flexbox 📦

Learn how to arrange, align and position elements easily using CSS Flexbox.

What is Flexbox?

Flexbox is a CSS layout system used to arrange elements inside a container.

It is especially useful for creating flexible and responsive layouts.

1. display: flex

To use Flexbox, first make the parent element a flex container. 


.container {
    display: flex;
}

2. flex-direction

It decides whether items are arranged in a row or column. 


.container {
    display: flex;
    flex-direction: row;
}

For vertical arrangement: 


.container {
    display: flex;
    flex-direction: column;
}

3. justify-content

It controls the alignment of items along the main axis. 


.container {
    display: flex;
    justify-content: center;
}

Common values:

  • flex-start
  • center
  • flex-end
  • space-between
  • space-around

4. align-items

It controls alignment along the cross axis. 


.container {
    display: flex;
    align-items: center;
}

5. gap

The gap property creates space between flex items. 


.container {
    display: flex;
    gap: 20px;
}

Flexbox Example 💻


.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

This places the items next to each other, centers them and adds space between them.

Important Points ⭐

  • display: flex creates a Flexbox container.
  • flex-direction controls row or column.
  • justify-content controls main-axis alignment.
  • align-items controls cross-axis alignment.
  • gap creates space between items.
  • Flexbox is useful for responsive layouts.
