🌐 IPv4 & IPv6

Learn the two major versions of the Internet Protocol used for addressing devices.

🔢 What is IPv4?

IPv4 stands for Internet Protocol Version 4.

IPv4 uses a 32-bit address.

Example: 192.168.1.10

🔢 What is IPv6?

IPv6 stands for Internet Protocol Version 6.

IPv6 uses a 128-bit address.

Example: 2001:db8::1

⚖️ IPv4 vs IPv6

🔹 IPv4 → 32-bit address

🔹 IPv6 → 128-bit address

🔹 IPv4 → Written using decimal numbers

🔹 IPv6 → Written using hexadecimal numbers

🔹 IPv6 provides a much larger address space

📱 Simple Example

IPv4:

192.168.1.10

IPv6:

2001:db8::1

Both can be used to identify devices for network communication.

🛡️ Why IPv6 is Needed?

The number of devices connected to networks has grown significantly.

IPv6 provides a much larger number of possible addresses than IPv4.

🛡️ Importance in Cybersecurity

Security professionals should understand both IPv4 and IPv6 because modern networks can use either or both protocols.

📝 Key Points

• IPv4 = Internet Protocol Version 4

• IPv6 = Internet Protocol Version 6

• IPv4 uses 32 bits

• IPv6 uses 128 bits

• IPv6 provides a much larger address space
