Networking Fundamentals 🌐

Learn the basic networking concepts that are important for cybersecurity.

🌐 What is a Computer Network?

A computer network is a group of computers and devices connected together to communicate and share information.

Example: Your laptop and mobile phone connected to the same Wi-Fi network form a small network.

📍 IP Address

An IP address is a unique address used to identify a device on a network.

Example:

192.168.1.10

It is similar to a house address, but for devices on a network.

🔗 MAC Address

A MAC address is a hardware address associated with a network interface.

Example:

00:1A:2B:3C:4D:5E

IP addresses can change, while a MAC address is generally associated with the network interface hardware.

🚪 Ports

Ports help a device identify which network service or application should receive traffic.

  • 80 — HTTP
  • 443 — HTTPS
  • 22 — SSH
  • 53 — DNS

📡 Network Protocols

Protocols are rules that allow devices to communicate with each other.

  • HTTP/HTTPS — Web communication
  • DNS — Converts domain names into IP addresses
  • TCP — Reliable communication
  • UDP — Faster connectionless communication
  • SSH — Secure remote access

🔀 Router vs Switch

Router

A router connects different networks and helps forward packets between them.

Switch

A switch connects devices within a local network and forwards frames to the appropriate device.

🔎 DNS

DNS stands for Domain Name System.

It converts human-readable domain names into IP addresses.

Example:

example.com → IP address

🔐 Why Networking is Important in Cybersecurity?

Ethical hackers and security professionals need networking knowledge to understand how devices communicate and how network traffic works.

Networking knowledge is useful when working with tools such as Wireshark, Nmap and Burp Suite in authorized security labs.

📌 Key Points to Remember

  • A network connects devices for communication.
  • IP address identifies a device on a network.
  • MAC address identifies a network interface.
  • Ports identify network services.
  • Protocols define communication rules.
  • DNS converts domain names to IP addresses.
  • Networking is an important foundation for cybersecurity.
