Python User Input ⌨️

Learn how to take information from the user using Python's input() function.

📌 What is User Input?

User input means taking information from the user while the Python program is running.

Python uses the input() function to take information from the user. 

name = input("Enter your name: ")

print("Hello", name)

📝 1. input() Function

The input() function displays a message and waits for the user to enter something. 

name = input("Enter your name: ")

print(name)

If the user enters: Harshika 

Harshika

🔤 2. Taking String Input

By default, input() takes the entered value as a string. 

name = input("Enter your name: ")

college = input("Enter your college: ")

print("Name:", name)
print("College:", college)

🔢 3. Taking Integer Input

To take a whole number, use int(). 

age = int(input("Enter your age: "))

print("Your age is", age)

Example: 

Enter your age: 18

Your age is 18

🔢 4. Taking Decimal Input

To take decimal numbers, use float(). 

height = float(input("Enter your height: "))

print("Height:", height)

➕ 5. Adding Two Numbers

We can take two numbers from the user and add them. 

num1 = int(input("Enter first number: "))

num2 = int(input("Enter second number: "))

sum = num1 + num2

print("Sum:", sum)

Output: 

Enter first number: 10
Enter second number: 20

Sum: 30

🌍 6. Real-Life Uses

User input is used in many applications.

  • Login forms
  • Registration forms
  • ATM applications
  • Banking systems
  • Student applications
  • Cybersecurity tools

⭐ Important Points

  • input() is used to take user input.
  • Input is treated as a string by default.
  • Use int() for integer values.
  • Use float() for decimal values.
  • User input makes programs interactive.
