🔧 Network Troubleshooting Commands

Learn basic commands used to check and troubleshoot network connectivity.

📡 1. ping

The ping command checks whether a device or host is reachable over a network. 

ping google.com

It can also show response time.

💻 2. ipconfig

On Windows, ipconfig displays network configuration information. 

ipconfig

It can show information such as IP address, subnet mask and default gateway.

🌐 3. ifconfig / ip

Linux systems commonly use the ip command to view network configuration. 

ip addr

🛣️ 4. tracert / traceroute

These commands help show the path packets take toward a destination.

Windows: 

tracert google.com

Linux: 

traceroute google.com

🔎 5. nslookup

nslookup can be used to query DNS information and check how domain names resolve. 

nslookup google.com

🧪 Basic Troubleshooting Process

If Internet is not working:

1️⃣ Check Wi-Fi or cable connection

2️⃣ Check IP configuration

3️⃣ Ping the default gateway

4️⃣ Ping a known external host

5️⃣ Check DNS using nslookup

📝 Key Points

• ping → checks connectivity

• ipconfig → Windows network configuration

• ip addr → Linux network configuration

• tracert/traceroute → shows network path

• nslookup → checks DNS resolution
