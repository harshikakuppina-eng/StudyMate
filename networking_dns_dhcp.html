📖 DNS & DHCP

Learn how DNS translates domain names and how DHCP provides network configuration.

🌐 What is DNS?

DNS stands for Domain Name System.

DNS translates human-readable domain names into IP addresses.

Example:

example.com → IP address

🔄 How DNS Works

When you enter a website name into your browser, the device needs to find the corresponding IP address.

DNS helps perform this name-to-address lookup.

📡 What is DHCP?

DHCP stands for Dynamic Host Configuration Protocol.

DHCP automatically provides network configuration information to devices.

⚙️ What Can DHCP Provide?

• IP address

• Subnet mask

• Default gateway

• DNS server information

🏠 Simple Example

When your laptop connects to your home Wi-Fi, DHCP can provide the laptop with an IP address and other network settings.

When you type a website name, DNS can help find the IP address associated with that name.

🛡️ Importance in Cybersecurity

DNS and DHCP are important when analyzing network communication, troubleshooting networks and investigating suspicious activity.

📝 Key Points

• DNS = Domain Name System

• DNS maps domain names to IP addresses

• DHCP = Dynamic Host Configuration Protocol

• DHCP automatically provides network settings
