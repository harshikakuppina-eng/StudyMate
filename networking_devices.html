🔌 Network Devices

Learn about common devices used to connect computers and networks.

🔀 What is a Switch?

A switch connects multiple devices within a local network.

It forwards data to the appropriate device based on network information.

Example: Computers connected inside a college lab.

📡 What is a Router?

A router connects different networks.

It helps forward packets from one network to another.

Example: A home Wi-Fi router connects your local devices to the Internet.

🔌 What is a Hub?

A hub is a basic networking device that sends incoming data to all connected ports.

Hubs are mostly considered legacy technology and are not commonly used in modern networks.

🌉 What is a Gateway?

A gateway acts as a connection point between different networks or systems.

It can translate or route communication between networks that may use different technologies or protocols.

⚖️ Switch vs Router

🔀 Switch: Mainly connects devices within a local network.

📡 Router: Connects different networks.

📚 Simple Network

A basic home network can look like:

💻 Laptop → 🔀 Switch / 📡 Router → 🌐 Internet

🛡️ Importance in Cybersecurity

Security professionals need to understand network devices because these devices control or forward network traffic.

📝 Key Points

• Hub → Sends data to connected ports

• Switch → Connects devices in a local network

• Router → Connects different networks

• Gateway → Connects different networks or systems
