Python Conditions 🤔

Learn how Python makes decisions using if, elif and else.

1. if Statement

What is if?

The if statement is used when we want Python to perform an action only when a condition is true. 

age = 18

if age >= 18:
    print("You are an adult")

Here, Python checks whether age is greater than or equal to 18.

2. if / else

else runs when the if condition is false. 

age = 16

if age >= 18:
    print("You are an adult")
else:
    print("You are not an adult")

3. elif

elif means "else if". It is used when we have multiple conditions. 

marks = 75

if marks >= 90:
    print("A Grade")
elif marks >= 60:
    print("B Grade")
else:
    print("C Grade")

4. Comparison Operators

Comparison operators compare two values.

  • == → Equal to
  • != → Not equal to
  • > → Greater than
  • < → Less than
  • >= → Greater than or equal to
  • <= → Less than or equal to
a = 10
b = 20

print(a == b)
print(a < b)

5. Logical Operators

Logical operators combine multiple conditions.

  • and → Both conditions must be true
  • or → At least one condition must be true
  • not → Reverses the result
age = 20
student = True

if age >= 18 and student:
    print("Adult student")

6. Real-Life Example 🎓

Conditions can be used to check whether a student passed an exam. 

marks = 65

if marks >= 40:
    print("You passed!")
else:
    print("You failed!")
