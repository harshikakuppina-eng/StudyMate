Variables & Data Types 📦

Learn how JavaScript stores and handles different types of data.

1. What is a Variable?

A variable is a container used to store data. In JavaScript, we can create variables using let, const, and var. 


let name = "Harshika";
let age = 18;

console.log(name);
console.log(age);

2. let

let is used when the value of a variable may change later. 


let age = 18;

age = 19;

console.log(age);

3. const

const is used when the value should not be changed. 


const college = "Aditya University";

console.log(college);

4. JavaScript Data Types

Common JavaScript data types are:

  • String
  • Number
  • Boolean
  • Undefined
  • Null
  • Object

5. String

A string stores text. 


let name = "Harshika";

console.log(name);

6. Number

A number stores numerical values. 


let age = 18;
let marks = 85.5;

console.log(age);
console.log(marks);

7. Boolean

Boolean stores either true or false. 


let isStudent = true;

console.log(isStudent);

8. Example


let name = "Harshika";
let age = 18;
let isStudent = true;

console.log(name);
console.log(age);
console.log(isStudent);

Quick Summary 🧠

  • let → value can be changed
  • const → value should not be changed
  • String → text
  • Number → numbers
  • Boolean → true or false
