HTML Basics 🌐

Learn the basics of HTML and how web pages are created.

1. What is HTML?

HTML stands for HyperText Markup Language.

HTML is used to create the structure of a web page.

Simple ga cheppali ante, HTML = Web page structure.

2. Basic HTML Structure

Every HTML page normally has a basic structure. 

<!DOCTYPE html>

<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

</body>

</html>

3. HTML Tags

HTML uses tags to tell the browser what each element means. 

<h1>Heading</h1>

<p>This is a paragraph.</p>

<button>Click Me</button>

Most HTML tags have an opening tag and a closing tag.

4. Headings

HTML provides six heading levels: 

<h1>Main Heading</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

h1 is the largest/main heading, while h6 is the smallest.

5. Paragraph

The <p> tag is used to create a paragraph. 

<p>
Welcome to StudyMate.
Learn coding step by step.
</p>

6. Links

The <a> tag is used to create a link. 

<a href="https://example.com">
Visit Website
</a>

href tells the browser where the link should go.

7. Images

The <img> tag is used to display an image. 

<img src="photo.jpg"
     alt="My Photo">

src → image location
alt → alternative text

8. HTML Comments

Comments are notes inside HTML code. They are not displayed on the web page. 

<!-- This is a comment -->

⭐ Important Points

  • HTML creates web page structure.
  • HTML uses tags.
  • <h1> to <h6> are headings.
  • <p> creates paragraphs.
  • <a> creates links.
  • <img> displays images.
