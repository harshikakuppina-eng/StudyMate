Python Tuples 📦

Learn how to store multiple values that cannot be changed.

What is a Tuple?

A tuple is used to store multiple values in a single variable.

Tuples are similar to lists, but their values cannot be changed after creation. 

colors = ("red", "blue", "green")

print(colors)

1. Creating a Tuple 📝

We create a tuple using round brackets (). 

subjects = ("Python", "Linux", "Networking")

print(subjects)

Output:

('Python', 'Linux', 'Networking')

2. Access Tuple Items 🔢

Tuple items can be accessed using their index. 

colors = ("red", "blue", "green")

print(colors[0])
print(colors[1])
print(colors[2])

Output:

red
blue
green

3. Negative Index 🔄

Negative indexing starts from the end of the tuple. 

colors = ("red", "blue", "green")

print(colors[-1])
print(colors[-2])

Output:

green
blue

4. Tuple Values Cannot Be Changed 🔒

Once a tuple is created, we cannot directly change its items. 

colors = ("red", "blue", "green")

# This will cause an error:
# colors[0] = "yellow"

This is called immutability.

5. Find Tuple Length 📏

The len() function tells us how many items are present. 

subjects = ("Python", "Linux", "Networking")

print(len(subjects))

Output:

3

6. Loop Through a Tuple 🔄

We can use a for loop to display each item. 

subjects = ("Python", "Linux", "Networking")

for subject in subjects:
    print(subject)

Output:

Python
Linux
Networking

7. Useful Tuple Methods 🛠️

Tuples have some useful built-in methods. 

numbers = (10, 20, 10, 30)

print(numbers.count(10))
print(numbers.index(20))

Output:

2
1

count() → counts how many times a value appears.

index() → finds the position of a value.

List vs Tuple ⚖️

List:

subjects = ["Python", "Linux"]

subjects[0] = "Cybersecurity"

List values can be changed.

Tuple:

subjects = ("Python", "Linux")

# subjects[0] = "Cybersecurity"

Tuple values cannot be changed.

Real-Life Example 🌍

Fixed Student Details

student_details = (
    "Harshika",
    "BSc Cybersecurity",
    3
)

print("Name:", student_details[0])
print("Course:", student_details[1])
print("Semester:", student_details[2])

Tuple is useful when data should remain fixed and should not be accidentally changed.
