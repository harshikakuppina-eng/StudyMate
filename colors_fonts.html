7️⃣ Colors, Fonts & Text 🎨

Learn how to make webpages attractive using CSS colors, fonts and text properties.

1. CSS Colors

CSS allows us to change the color of text and backgrounds. 


h1 {
    color: blue;
}

p {
    color: green;
}

2. Background Color

We can change the background color of an element. 


body {
    background-color: lightblue;
}

3. Font Size

The font-size property changes the size of text. 


p {
    font-size: 20px;
}

4. Font Family

Font-family changes the type of font used. 


body {
    font-family: Arial, sans-serif;
}

5. Text Alignment

We can align text to the left, center or right. 


h1 {
    text-align: center;
}

6. Font Weight

Font-weight is used to make text normal or bold. 


p {
    font-weight: bold;
}

Important Points ⭐

  • color changes text color.
  • background-color changes background color.
  • font-size changes text size.
  • font-family changes the font.
  • text-align controls text position.
  • font-weight controls text thickness.
