Headings, Paragraphs & Text ✍️

Learn how to display and format text using HTML.

1. Headings

HTML provides six different heading tags. 

<h1>Main Heading</h1>
<h2>Second Heading</h2>
<h3>Third Heading</h3>
<h4>Fourth Heading</h4>
<h5>Fifth Heading</h5>
<h6>Sixth Heading</h6>

<h1> is the main and largest heading.
<h6> is the smallest heading.

2. Paragraphs

The <p> tag is used to create paragraphs. 

<p>
HTML is used to create web pages.
</p>

3. Bold Text

The <b> tag makes text bold. 

<b>Important Text</b>

Result: Important Text

4. Italic Text

The <i> tag makes text italic. 

<i>This is italic text</i>

Result: This is italic text

5. Underlined Text

The <u> tag underlines text. 

<u>Important</u>

Result: Important

6. Strong & Emphasis

<strong> represents important text. 

<strong>Warning!</strong>

<em> is used to emphasize text. 

<em>Be careful!</em>

7. Line Break

The <br> tag moves text to a new line. 

Hello<br>
World

Result:
Hello
World

8. Horizontal Line

The <hr> tag creates a horizontal line. 

<hr>

⭐ Important Points

  • <h1> to <h6> → Headings
  • <p> → Paragraph
  • <b> → Bold text
  • <i> → Italic text
  • <u> → Underlined text
  • <br> → Line break
  • <hr> → Horizontal line
