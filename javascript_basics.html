1️⃣1️⃣ JavaScript Basics ⚡

Learn the basics of JavaScript and make webpages interactive.

What is JavaScript?

JavaScript is a programming language used to make webpages interactive and dynamic.

For example:

  • Button clicks
  • Pop-up messages
  • Changing text
  • Calculations
  • Interactive forms

1. JavaScript in HTML

JavaScript can be written inside the <script> tag. 


<script>

alert("Hello StudyMate!");

</script>

2. Variables

Variables are used to store values. 


let name = "Harshika";

let age = 18;

console.log(name);
console.log(age);

3. console.log()

console.log() is used to display information in the browser console. 


console.log("Hello World!");

4. JavaScript Function

A function is a block of code that performs a particular task. 


function greet() {

    console.log("Welcome to StudyMate!");

}

greet();

5. Button Click

JavaScript can perform an action when a button is clicked. 


function showMessage() {

    alert("Welcome to StudyMate!");

}

Simple JavaScript Example 💻

Important Points ⭐

  • JavaScript makes webpages interactive.
  • JavaScript code can be written using script tags.
  • Variables store data.
  • console.log() displays information in the console.
  • Functions contain reusable code.
  • JavaScript can respond to button clicks.
