🔟 Responsive Design 📱💻

Learn how to create webpages that automatically adjust to different screen sizes.

What is Responsive Design?

Responsive Design means creating a website that works properly on different devices.

  • 📱 Mobile phones
  • 📲 Tablets
  • 💻 Laptops
  • 🖥️ Desktop computers

1. Viewport

The viewport meta tag helps webpages display correctly on mobile devices. 


<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

2. Media Queries

Media queries allow us to apply different CSS rules depending on the screen size. 


@media (max-width: 600px) {

    body {
        font-size: 16px;
    }

}

3. Responsive Layout

We can change a row layout into a column layout when the screen becomes smaller. 


.container {
    display: flex;
}

@media (max-width: 600px) {

    .container {
        flex-direction: column;
    }

}

4. Responsive Images

Images should not become wider than their container. 


img {
    max-width: 100%;
    height: auto;
}

Responsive Example 💻


.container {
    display: flex;
    gap: 20px;
}

@media (max-width: 600px) {

    .container {
        flex-direction: column;
    }

}

On a large screen the boxes appear in a row. On a small screen they appear one below another.

Important Points ⭐

  • Responsive Design supports different devices.
  • Viewport helps mobile browsers display pages correctly.
  • Media queries apply CSS based on screen size.
  • Flexbox helps create flexible layouts.
  • Images can be made responsive using max-width.
