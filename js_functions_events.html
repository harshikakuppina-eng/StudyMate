Functions & Events ⚡

Learn how functions organize code and how events make webpages interactive.

1. What is a Function?

A function is a reusable block of code that performs a particular task. 


function greet() {
    console.log("Hello Harshika!");
}

greet();

2. Function with Parameters

Parameters allow us to pass information to a function. 


function greet(name) {
    console.log("Hello " + name);
}

greet("Harshika");

3. Function with Return

A function can return a value using the return keyword. 


function add(a, b) {
    return a + b;
}

let result = add(10, 20);

console.log(result);

4. What is an Event?

An event is an action that happens on a webpage.

Examples:

  • Clicking a button
  • Typing in a textbox
  • Moving the mouse
  • Submitting a form

5. Click Event

JavaScript can perform an action when a user clicks a button. 


function showMessage() {
    alert("Button clicked!");
}

Quick Summary 🧠

  • Function → reusable block of code
  • Parameter → information passed to a function
  • return → sends a value back
  • Event → action performed by the user/browser
  • onclick → runs code when an element is clicked
