Authentication & Password Security 🔑

Learn how authentication works and how passwords can be protected from unauthorized access.

🔐

What is Authentication?

Authentication is the process of verifying whether a person or system is really who they claim to be.

For example, entering your username and password to access an account is a form of authentication.

Authentication Factors

  • Something you know – Password or PIN
  • Something you have – Phone, security key or OTP device
  • Something you are – Fingerprint or facial recognition

What is a Password?

A password is a secret value used to prove that a user is authorized to access an account.

Strong passwords make unauthorized access more difficult.

Strong Password Practices 🛡️

  • Use long and unique passwords.
  • Do not reuse the same password everywhere.
  • Avoid easily guessed personal information.
  • Use a trusted password manager when appropriate.
  • Enable multi-factor authentication.

Password Hashing

Websites should not normally store user passwords as plain text.

Instead, passwords should be processed using a secure password-hashing algorithm before being stored.

Hashing converts the password into a value that is designed to be difficult to reverse.

Hashing vs Encryption

  • Hashing – One-way process commonly used for password verification.
  • Encryption – Data is transformed so it can later be decrypted using a key.

Multi-Factor Authentication (MFA)

MFA adds another verification step after the password.

Example:

  1. Enter username and password.
  2. Verify using an authenticator app or security key.
  3. Access the account.

MFA can provide additional protection even when a password is compromised.

Common Authentication Risks ⚠️

  • Weak passwords
  • Password reuse
  • Storing passwords insecurely
  • Missing multi-factor authentication
  • Account enumeration
  • Session management weaknesses

Example 💡

Imagine a student portal with a login page. A secure system verifies the user's credentials, protects stored passwords using appropriate password hashing, and may require MFA.

This helps prevent unauthorized users from accessing student accounts.

Ethical Security Testing

Security professionals may test authentication systems to identify weaknesses, but testing must be performed only on systems they own or have explicit permission to assess.

Key Points 📝

  • Authentication verifies identity.
  • Passwords are one authentication factor.
  • Strong and unique passwords improve security.
  • Passwords should be securely hashed before storage.
  • MFA provides an additional layer of protection.
  • Authentication testing requires authorization.
