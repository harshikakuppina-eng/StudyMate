Python Dictionaries 📖

Learn how to store data using key and value pairs.

What is a Dictionary?

A dictionary is used to store data in key : value pairs.

Each key is used to access its value. 

student = {
    "name": "Harshika",
    "age": 18,
    "course": "Cybersecurity"
}

1. Access Dictionary Values 🔑

We can access a value using its key. 

student = {
    "name": "Harshika",
    "age": 18
}

print(student["name"])
print(student["age"])

Output:

Harshika
18

2. Add a New Value ➕

We can add a new key and value to a dictionary. 

student = {
    "name": "Harshika",
    "age": 18
}

student["course"] = "Cybersecurity"

print(student)

3. Update a Value ✏️

We can change an existing value using its key. 

student = {
    "name": "Harshika",
    "age": 18
}

student["age"] = 19

print(student)

4. Remove Values 🗑️

We can remove a value using pop() or del. 

student = {
    "name": "Harshika",
    "age": 18,
    "course": "Cybersecurity"
}

student.pop("age")

print(student)

5. Using get() 🔎

The get() method is another way to access a dictionary value. 

student = {
    "name": "Harshika",
    "age": 18
}

print(student.get("name"))

Output:

Harshika

6. Loop Through Dictionary 🔄

We can use a for loop to display dictionary items. 

student = {
    "name": "Harshika",
    "course": "Cybersecurity",
    "year": 2
}

for key, value in student.items():
    print(key, ":", value)

Output:

name : Harshika
course : Cybersecurity
year : 2
