8️⃣ CSS Box Model 📦

Learn how CSS controls the space around HTML elements.

What is Box Model?

Every HTML element is treated like a box. The CSS Box Model consists of four parts:

  • Content
  • Padding
  • Border
  • Margin

1. Content

Content is the actual text, image or information inside an element. 


div {
    width: 200px;
    height: 100px;
}

2. Padding

Padding is the space between the content and the border. 


div {
    padding: 20px;
}

3. Border

Border creates a boundary around the element. 


div {
    border: 2px solid black;
}

4. Margin

Margin creates space outside the element. 


div {
    margin: 20px;
}

Box Model Example 💻


.box {
    width: 200px;
    padding: 20px;
    border: 5px solid black;
    margin: 30px;
}

Here width = content size, padding adds inner space, border surrounds the box, and margin creates outer space.

Important Points ⭐

  • Content is the actual element content.
  • Padding is inside the border.
  • Border surrounds the element.
  • Margin is outside the border.
  • Box Model helps control webpage layout.
