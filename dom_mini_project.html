DOM & Mini Project 🖥️

Learn how JavaScript interacts with HTML using the DOM.

1. What is DOM?

DOM stands for Document Object Model.

The DOM represents an HTML webpage as objects. JavaScript can use these objects to change the webpage.

2. Selecting an Element

We can select an HTML element using getElementById(). 


let heading = document.getElementById("title");

console.log(heading);

3. Changing Text

JavaScript can change the text of an HTML element. 


document.getElementById("title").innerText =
    "Welcome to StudyMate!";

Quick Summary 🧠

  • DOM → represents the webpage
  • getElementById() → selects an element
  • innerText → changes text
  • Events → respond to user actions
