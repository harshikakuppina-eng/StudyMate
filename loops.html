Python Loops 🔁

Learn how to repeat a block of code using for loops, while loops, break and continue.

What are Loops?

A loop is used to repeat a block of code multiple times.

Example: If you want to print "Hello" 5 times, instead of writing print() five times, you can use a loop.

1. For Loop 🔄

A for loop is used when we want to repeat something a specific number of times or go through items one by one. 

for i in range(5):
    print(i)

Output:

0
1
2
3
4

2. range() Function 🔢

range() generates a sequence of numbers. 

for i in range(1, 6):
    print(i)

Output:

1
2
3
4
5

Remember: the ending number is not included.

3. Loop Through a List 📋

We can use a loop to access each item in a list. 

subjects = ["Python", "Networking", "Cybersecurity"]

for subject in subjects:
    print(subject)

Output:

Python
Networking
Cybersecurity

4. While Loop ⏳

A while loop keeps running as long as the condition is true. 

i = 1

while i <= 5:
    print(i)
    i = i + 1

Output:

1
2
3
4
5

Here, the loop stops when i becomes 6.

5. break Statement 🛑

break is used to completely stop a loop. 

for i in range(10):

    if i == 5:
        break

    print(i)

Output:

0
1
2
3
4

When i becomes 5, the loop stops.

6. continue Statement ⏭️

continue skips the current iteration and moves to the next iteration. 

for i in range(5):

    if i == 2:
        continue

    print(i)

Output:

0
1
3
4

Here, 2 is skipped.

7. Nested Loop 🔁🔁

A loop inside another loop is called a nested loop. 

for i in range(2):

    for j in range(3):
        print(i, j)

Output:

0 0
0 1
0 2
1 0
1 1
1 2

Real-Life Example 🎯

Suppose you have to study 5 topics. Instead of writing the same instruction 5 times, you can use a loop. 

topics = ["Python", "Linux", "Networking", "Cybersecurity", "Forensics"]

for topic in topics:
    print("Study:", topic)

Output:

Study: Python
Study: Linux
Study: Networking
Study: Cybersecurity
Study: Forensics
