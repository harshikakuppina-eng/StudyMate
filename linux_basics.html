Linux Basics 🐧

Learn basic Linux concepts and commands that are useful for cybersecurity and system administration.

🐧

What is Linux?

Linux is an open-source operating system used in computers, servers, cloud systems and many cybersecurity environments.

Kali Linux, Ubuntu and Debian are examples of Linux-based operating systems.

💻

What is a Terminal?

A terminal is a text-based interface where we can communicate with the operating system using commands.

Cybersecurity professionals frequently use terminals to manage systems and run security tools.

⌨️

Basic Linux Commands

  • pwd – Shows the current directory.
  • ls – Lists files and folders.
  • cd – Changes the directory.
  • mkdir – Creates a new directory.
  • touch – Creates a new file.
  • cat – Displays file contents.
  • clear – Clears the terminal screen.
💡

Simple Example

Suppose you want to see which folder you are currently working in. 

pwd

The terminal will display the path of your current directory.

📁

Linux File System

Linux organizes files and folders in a hierarchical structure.

  • / – Root directory
  • /home – User directories
  • /etc – Configuration files
  • /tmp – Temporary files
  • /var – Variable data and logs
🔐

Linux File Permissions

Linux uses permissions to control who can read, write or execute a file.

The three basic permissions are:

  • r – Read
  • w – Write
  • x – Execute
🛡️

Why Linux is Important in Cybersecurity

Linux is widely used in cybersecurity because it provides powerful command-line tools and gives professionals detailed control over systems and networks.

Many security tools and cybersecurity labs are available for Linux.

⚠️

Safe Practice

Practice Linux commands only on your own computer, virtual machine or authorized laboratory environment.

Never use commands to access or modify systems without permission.

⭐

Key Points

  • Linux is an open-source operating system.
  • The terminal allows users to run commands.
  • pwd shows the current directory.
  • ls lists files and folders.
  • Linux uses file permissions.
  • Linux is widely used in cybersecurity.
