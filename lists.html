Python Lists 📋

Learn how to store and manage multiple values using Python lists.

What is a List?

A list is used to store multiple values in a single variable.

Lists are written using square brackets [ ]. 

subjects = ["Python", "Linux", "Networking"]

print(subjects)

Output: 

['Python', 'Linux', 'Networking']

1. Accessing List Items 🔍

Each item in a list has an index number.

Python starts indexing from 0. 

subjects = ["Python", "Linux", "Networking"]

print(subjects[0])
print(subjects[1])
print(subjects[2])

Output: 

Python
Linux
Networking

2. Changing List Items ✏️

We can change an item using its index. 

subjects = ["Python", "Linux", "Networking"]

subjects[1] = "Cybersecurity"

print(subjects)

Output: 

['Python', 'Cybersecurity', 'Networking']

3. Adding Items ➕

The append() method adds a new item to the end of a list. 

subjects = ["Python", "Linux"]

subjects.append("Networking")

print(subjects)

Output: 

['Python', 'Linux', 'Networking']

4. Removing Items ❌

The remove() method removes a specific item. 

subjects = ["Python", "Linux", "Networking"]

subjects.remove("Linux")

print(subjects)

Output: 

['Python', 'Networking']

5. Finding List Length 📏

The len() function tells us how many items are present in a list. 

subjects = ["Python", "Linux", "Networking"]

print(len(subjects))

Output: 

3

6. Loop Through a List 🔁

We can use a for loop to print every item in a list. 

subjects = ["Python", "Linux", "Networking"]

for subject in subjects:
    print(subject)

Output: 

Python
Linux
Networking

7. Useful List Methods 🛠️

append() → Adds an item

remove() → Removes an item

sort() → Sorts the list

reverse() → Reverses the list

len() → Finds the number of items

numbers = [5, 2, 8, 1]

numbers.sort()

print(numbers)

Output: 

[1, 2, 5, 8]

8. Real-Life Example 🎯

Imagine you want to store your cybersecurity tools in one place. 

tools = [
    "Wireshark",
    "Burp Suite",
    "Nmap",
    "Volatility"
]

for tool in tools:
    print("Learning:", tool)

Output: 

Learning: Wireshark
Learning: Burp Suite
Learning: Nmap
Learning: Volatility
