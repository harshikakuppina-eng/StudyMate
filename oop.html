Object-Oriented Programming 🧩

Learn Classes, Objects, Attributes and Methods step by step.

What is OOP?

OOP stands for Object-Oriented Programming.

In OOP, we organize our program using classes and objects.

Real-life things like students, cars and bank accounts can be represented as objects.

1. Class

A class is like a blueprint for creating objects. 

class Student:
    pass

Here, Student is a class.

2. Object

An object is an actual instance created from a class. 

class Student:
    pass

student1 = Student()

Here, student1 is an object of the Student class.

3. __init__()

__init__() is a special method that runs automatically when an object is created. 

class Student:

    def __init__(self, name, course):
        self.name = name
        self.course = course

student1 = Student("Harshika", "Cybersecurity")

print(student1.name)
print(student1.course)

Output:

Harshika
Cybersecurity

4. What is self?

self refers to the current object. 

class Student:

    def __init__(self, name):
        self.name = name

Here, self.name stores the name for that particular object.

5. Attributes

Attributes are the data or properties belonging to an object. 

class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age

student1 = Student("Harshika", 18)

print(student1.name)
print(student1.age)

6. Methods

A method is a function inside a class. 

class Student:

    def __init__(self, name):
        self.name = name

    def study(self):
        print(self.name, "is studying Python")

student1 = Student("Harshika")

student1.study()

Output:

Harshika is studying Python

7. Multiple Objects

One class can be used to create many objects. 

class Student:

    def __init__(self, name):
        self.name = name

student1 = Student("Harshika")
student2 = Student("Rahul")

print(student1.name)
print(student2.name)

Output:

Harshika
Rahul

🔐 Cybersecurity Example

We can represent a cybersecurity tool using a class. 

class SecurityTool:

    def __init__(self, name):
        self.name = name

    def scan(self):
        print(self.name, "is scanning...")

tool = SecurityTool("Network Scanner")

tool.scan()

Output:

Network Scanner is scanning...

⭐ Important Points

✅ Class → Blueprint

✅ Object → Actual instance

✅ __init__() → Initializes object

✅ self → Current object

✅ Attribute → Object data

✅ Method → Function inside class
