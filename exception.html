PYTHON EXCEPTION HANDLING

Exception Handling 🛡️

Learn how to handle errors in Python without stopping your program.

What is an Exception?

An exception is an error that occurs while a Python program is running.

Example: 

number = 10
result = number / 0

This causes a ZeroDivisionError.

1. try

The try block contains code that might cause an error. 

try:
    number = 10 / 0

2. except

The except block handles the error. 

try:
    number = 10 / 0

except:
    print("Something went wrong")

Output:

Something went wrong

3. Specific Exception

We can handle a specific type of error. 

try:
    number = 10 / 0

except ZeroDivisionError:
    print("Cannot divide by zero")

Output:

Cannot divide by zero

4. else

The else block runs when there is no error. 

try:
    number = 10 / 2

except ZeroDivisionError:
    print("Cannot divide by zero")

else:
    print("Calculation successful")
    print(number)

Output:

Calculation successful
5.0

5. finally

The finally block runs whether an error occurs or not. 

try:
    number = 10 / 2

except:
    print("Error")

finally:
    print("Program finished")

Output:

Program finished

6. Multiple Exceptions

We can handle different errors separately. 

try:
    number = int("hello")

except ValueError:
    print("Invalid number")

except ZeroDivisionError:
    print("Cannot divide by zero")

Output:

Invalid number

🔐 Cybersecurity Example

Exception handling can help a security application continue running when unexpected input is received. 

try:
    attempts = int("five")

    print("Login attempts:", attempts)

except ValueError:
    print("Invalid input received")

Output:

Invalid input received

⭐ Important Points

✅ try → Code that may cause an error

✅ except → Handles the error

✅ else → Runs when there is no error

✅ finally → Always runs

✅ Exception handling prevents unexpected program crashes
