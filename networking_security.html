🛡️ Network Security Basics

Learn the basic concepts used to protect computer networks from security threats.

🔐 What is Network Security?

Network security is the practice of protecting networks, devices and data from unauthorized access, attacks and misuse.

🎯 Main Goals

Network security commonly focuses on:

✔ Confidentiality

✔ Integrity

✔ Availability

These three goals are known as the CIA Triad.

🔥 Firewall

A firewall monitors and controls network traffic based on security rules.

It can help block unwanted network connections.

🚨 IDS and IPS

IDS stands for Intrusion Detection System.

It detects suspicious activity and generates alerts.

IPS stands for Intrusion Prevention System.

It can detect and actively block suspicious traffic according to configured rules.

🔑 Authentication

Authentication verifies the identity of a user or device.

Example:

Username + Password + MFA

🛡️ Basic Security Practices

✔ Use strong passwords

✔ Enable MFA when available

✔ Keep software updated

✔ Use firewalls

✔ Monitor unusual network activity

✔ Secure Wi-Fi networks

📝 Key Points

• Network security protects network resources

• CIA = Confidentiality, Integrity, Availability

• Firewalls filter network traffic

• IDS detects suspicious activity

• IPS can help prevent suspicious activity
