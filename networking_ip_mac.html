🌐 IP Address & MAC Address

Learn how devices are identified and communicated with inside a computer network.

🌍 What is an IP Address?

An IP address is a numerical address given to a device on a network.

It helps devices identify and communicate with each other.

Example: 192.168.1.10

🏠 Private IP Address

A private IP address is used inside a local network such as your home, college or office.

Example: 192.168.1.10

🌎 Public IP Address

A public IP address is used to identify a network or device when communicating over the Internet.

Your Internet Service Provider generally provides the public IP address for your connection.

💻 What is a MAC Address?

MAC stands for Media Access Control.

A MAC address is a hardware identifier associated with a network interface.

Example: 00:1A:2B:3C:4D:5E

🔄 IP Address vs MAC Address

🌐 IP Address: Used for network communication.

💻 MAC Address: Identifies a network interface at the link layer.

🔄 IP Address: Can change depending on the network.

🔒 MAC Address: Normally associated with the network hardware/interface.

📱 Simple Example

Imagine your laptop is connected to your home Wi-Fi.

Your laptop may have:

IP Address → 192.168.1.10

MAC Address → 00:1A:2B:3C:4D:5E

The IP address helps with network communication, while the MAC address identifies the network interface on the local network.

🛡️ Importance in Cybersecurity

Cybersecurity professionals need to understand IP and MAC addresses because they are important when analyzing networks and investigating network activity.

📝 Key Points

• IP = Network address

• MAC = Network interface hardware identifier

• Private IP is used inside local networks

• Public IP is used for Internet communication

• IP addresses are important for routing

• MAC addresses are important on local networks
