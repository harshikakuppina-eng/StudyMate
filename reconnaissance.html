Reconnaissance 🔎

Learn the basics of information gathering used during authorized cybersecurity assessments.

What is Reconnaissance?

Reconnaissance is the process of collecting information about a target before a security assessment.

Security professionals use reconnaissance to understand the systems, services and publicly available information associated with a target.

Types of Reconnaissance

1. Passive Reconnaissance

Information is collected from publicly available sources without directly interacting with the target system.

Example: public websites, search engines and publicly available domain information.

2. Active Reconnaissance

Information is collected by directly interacting with the target system.

Active reconnaissance should only be performed when you have explicit permission.

What Information Can Be Collected?

  • Domain information
  • IP address information
  • DNS information
  • Publicly exposed services
  • Technology information
  • Public documents

Basic Reconnaissance Process

  1. Define the authorized target.
  2. Collect publicly available information.
  3. Identify useful technical information.
  4. Verify the collected information.
  5. Document the findings.

Simple Example 💡

Imagine you are performing a security assessment on your own website.

You might first identify the domain, understand its DNS information and determine which technologies are publicly visible.

This helps you understand the public attack surface and improve security.

Ethical Use 🛡️

Reconnaissance must be performed responsibly.

  • Test only systems you own or have permission to test.
  • Respect privacy and applicable laws.
  • Do not attempt to access private information.
  • Do not bypass authentication or security controls.

Key Points ⭐

  • Reconnaissance means information gathering.
  • It can be passive or active.
  • Passive reconnaissance uses public sources.
  • Active reconnaissance directly interacts with systems.
  • Active testing requires authorization.
