🔗 Links & Images

Learn how to add links and images to a webpage.

1. HTML Links

Links are used to move from one webpage to another.

Example:

<a href="https://www.google.com">
    Visit Google
</a>

Output: Visit Google

2. Link to Another Page

We can use links to open another page in our website. 

<a href="about.html">
    About Us
</a>

3. HTML Images

The <img> tag is used to display an image. 

<img src="image.jpg" alt="My Image">

src → image location

alt → alternative text

4. Image Example

5. Image as a Link

An image can also be used as a clickable link. 

<a href="https://www.google.com">

    <img src="image.jpg" alt="Google">

</a>

⭐ Important Points

  • <a> tag is used to create links.
  • href specifies the link destination.
  • <img> tag is used to display images.
  • src specifies the image location.
  • alt provides alternative text for an image.
