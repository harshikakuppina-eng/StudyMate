File Handling 📁

Learn how to read, write and manage files using Python.

What is File Handling?

File Handling means working with files using Python.

We can create, read, write and update files using Python.

Common file types include .txt, .csv and .log files.

1. Opening a File

Python uses the open() function to open a file. 

file = open("example.txt", "r")

Here "r" means read mode.

2. Reading a File

We can use read() to read the contents of a file. 

file = open("example.txt", "r")

content = file.read()

print(content)

file.close()

3. Writing to a File

"w" mode is used to write data to a file. 

file = open("example.txt", "w")

file.write("Hello Python!")

file.close()

If the file does not exist, Python can create it in this mode.

4. Append Data

"a" mode adds new data to the end of an existing file. 

file = open("example.txt", "a")

file.write("\nLearning Python")

file.close()

5. with open()

Using with open() is a better way to work with files because Python automatically handles closing the file. 

with open("example.txt", "r") as file:

    content = file.read()

    print(content)

6. File Modes

📖 r → Read

✍️ w → Write

➕ a → Append

🆕 x → Create a new file

🔐 Cybersecurity Example

Security applications often work with log files. For example, a program may read a log file and display its contents. 

log_data = """
Login successful
Failed login attempt
Failed login attempt
"""

with open("security.log", "w") as file:
    file.write(log_data)

print("Security log created")

Output:

Security log created

⭐ Important Points

✅ open() → Opens a file

✅ read() → Reads file content

✅ write() → Writes data

✅ append → Adds data

✅ close() → Closes a file

✅ with open() → Safely manages files
