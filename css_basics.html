🎨 CSS Basics

Learn how to style HTML webpages using CSS.

1. What is CSS?

CSS stands for Cascading Style Sheets.

CSS is used to design and style HTML webpages.

Example: changing colors, fonts, spacing, backgrounds and layouts.

2. CSS Syntax

Basic CSS syntax looks like this: 

selector {
    property: value;
}

Example: 

p {
    color: blue;
}

3. CSS Selector

A selector tells CSS which HTML element should be styled. 

p {
    color: red;
}

h1 {
    color: green;
}

4. Inline CSS

CSS can be written directly inside an HTML element. 

<p style="color: blue;">
    Hello World
</p>

Hello World

5. Internal CSS

CSS can also be written inside the <style> tag. 

<style>

p {
    color: blue;
}

</style>

6. External CSS

CSS can be written in a separate .css file. 

<link rel="stylesheet" href="style.css">

This is the method we are already using in our StudyMate project.

7. CSS Properties

Properties define what style we want to change. 

color: blue;

font-size: 20px;

background-color: yellow;

text-align: center;

8. CSS Example

This text is blue.

This text is bigger.

This text is centered.

⭐ Important Points

  • CSS stands for Cascading Style Sheets.
  • CSS is used to style HTML pages.
  • CSS has selectors, properties and values.
  • CSS can be Inline, Internal or External.
  • External CSS is stored in a .css file.
