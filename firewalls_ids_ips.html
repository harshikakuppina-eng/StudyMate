🔥 Firewalls & IDS/IPS

Learn how security systems monitor, filter and protect networks from suspicious activity.

🔥

What is a Firewall?

A firewall is a security system that monitors network traffic and decides whether traffic should be allowed or blocked.

It works like a security guard between a trusted network and an untrusted network.

🚪

How Does a Firewall Work?

A firewall checks network traffic using rules. Based on these rules, it can allow or block connections.

Example:

If a firewall rule allows HTTPS traffic, normal secure web traffic can pass through.

🧱

Types of Firewalls

1. Packet Filtering Firewall

Checks packets using information such as IP addresses, ports and protocols.

2. Stateful Firewall

Keeps track of active connections and makes decisions based on connection state.

3. Application Firewall

Monitors traffic related to applications and can inspect application-level requests.

👁️

What is IDS?

IDS stands for Intrusion Detection System.

An IDS monitors network or system activity and detects suspicious or potentially malicious behavior.

When suspicious activity is detected, it can generate an alert.

🛑

What is IPS?

IPS stands for Intrusion Prevention System.

An IPS detects suspicious activity and can take preventive action according to configured security rules.

⚖️

IDS vs IPS

IDS: Detects suspicious activity and mainly generates alerts.

IPS: Detects suspicious activity and can automatically take action to prevent it.

Easy way to remember: IDS = Detect, IPS = Prevent.

🔐

Firewall vs IDS/IPS

A firewall mainly controls whether network traffic is allowed or blocked according to security rules.

IDS focuses on detecting suspicious activity and generating alerts.

IPS focuses on detecting suspicious activity and taking preventive action.

💡

Simple Real-World Example

Imagine a college network.

The firewall controls which network connections are allowed.

The IDS watches network activity and alerts the administrator when suspicious behavior is detected.

The IPS can take configured preventive action when suspicious traffic is detected.

🛡️

Why are Firewalls & IDS/IPS Important?

They help organizations monitor and protect their networks.

  • Control network traffic
  • Detect suspicious activity
  • Generate security alerts
  • Help prevent unauthorized access
  • Improve network security monitoring
⚠️

Ethical Security Rule

Firewall, IDS and IPS testing should only be performed on systems and networks that you own or have explicit permission to test.

For learning, use your own computer, virtual machines or authorized cybersecurity labs.

📌

Key Points

🔥 Firewall → Controls network traffic

👁️ IDS → Detects and alerts

🛑 IPS → Detects and prevents

🔐 All three are important components of network security.
