🧩 OSI Model

Learn the seven layers of the Open Systems Interconnection model.

📚 What is the OSI Model?

OSI stands for Open Systems Interconnection.

It is a conceptual model that helps us understand how network communication works.

The OSI model has 7 layers.

7️⃣ Seven OSI Layers

7. Application — Provides network services to applications.

6. Presentation — Handles data formatting, encryption and compression.

5. Session — Manages communication sessions.

4. Transport — Provides end-to-end data delivery.

3. Network — Handles logical addressing and routing.

2. Data Link — Handles frames and local network communication.

1. Physical — Transmits bits through physical media.

🧠 Easy Way to Remember

From Layer 7 to Layer 1:

Application → Presentation → Session → Transport → Network → Data Link → Physical

📦 Simple Example

Suppose you open a website.

Your data moves through different networking layers while being transmitted across the network.

Each layer performs a specific role in communication.

🛡️ OSI Model & Cybersecurity

The OSI model helps cybersecurity professionals understand where different network technologies, attacks and security controls operate.

For example, IP addressing is associated with the Network layer, while MAC addressing is associated with the Data Link layer.

📝 Key Points

• OSI = Open Systems Interconnection

• OSI has 7 layers

• Layer 7 = Application

• Layer 4 = Transport

• Layer 3 = Network

• Layer 2 = Data Link

• Layer 1 = Physical
