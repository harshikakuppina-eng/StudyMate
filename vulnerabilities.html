Vulnerabilities 🔓

Learn what security vulnerabilities are, how they occur, and how cybersecurity professionals identify and reduce them.

⚠️

What is a Vulnerability?

A vulnerability is a weakness or security flaw in a computer system, application, network or device.

Attackers may try to take advantage of these weaknesses, so security professionals identify and fix them.

💡

Simple Example

Imagine a house has a broken window. The broken window is a weakness that could allow someone to enter the house.

In cybersecurity, a software weakness can similarly create an opportunity for unauthorized access.

🧩

Common Types of Vulnerabilities

  • Weak or default passwords
  • Outdated software
  • Misconfigured systems
  • Insecure network settings
  • Improper access control
  • Input validation problems
  • Security configuration errors
📊

Vulnerability vs Threat vs Risk

Vulnerability: A weakness in a system.

Threat: Something that could potentially cause harm.

Risk: The possibility and potential impact of a threat exploiting a vulnerability.

📋

What is CVE?

CVE stands for Common Vulnerabilities and Exposures.

CVE provides unique identifiers for publicly known cybersecurity vulnerabilities.

Example format: CVE-YYYY-NNNN

🔍

How Security Professionals Find Vulnerabilities

  1. Understand the system and its components.
  2. Identify possible weaknesses.
  3. Use authorized security testing tools.
  4. Analyze the results.
  5. Fix or reduce the identified weaknesses.
  6. Test again to verify the fix.
🛡️

Safe Practice

Vulnerability testing should only be performed on systems that you own or have explicit permission to test.

For learning, use your own website, local applications, CTF platforms or intentionally vulnerable training labs.

⭐

Key Points

  • Vulnerability means a security weakness.
  • Outdated software can contain vulnerabilities.
  • Strong configuration helps reduce security risks.
  • CVE identifies publicly known vulnerabilities.
  • Security testing must be authorized.
  • Finding vulnerabilities helps organizations improve security.
