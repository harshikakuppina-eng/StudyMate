Python Basics 🐍

Learn the basic concepts of Python step by step.

1. Introduction to Python

What is Python?

Python is a simple and powerful programming language. It is used for web development, automation, data science, cybersecurity and many other areas.

2. Variables

A variable is used to store data in a program. 

name = "Harshika"
age = 18

3. Data Types

Some common Python data types are:

  • String → "Hello"
  • Integer → 25
  • Float → 10.5
  • Boolean → True / False
  • List → [1, 2, 3]

4. Operators

Operators are used to perform calculations and comparisons. 

a = 10
b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)

5. Conditions

Conditions are used to make decisions in Python. 

age = 18

if age >= 18:
    print("You are eligible")
else:
    print("You are not eligible")

6. Loops

Loops are used to repeat a block of code. 

for i in range(5):
    print(i)

7. Functions

Functions are reusable blocks of code. 

def greet():
    print("Hello!")

greet()

8. Lists

Lists are used to store multiple values. 

fruits = ["Apple", "Mango", "Banana"]

print(fruits)
print(fruits[0])

9. User Input

The input() function is used to get information from the user. 

name = input("Enter your name: ")
print("Hello", name)
