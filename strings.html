Python Strings 🧵

Learn how to work with text and characters in Python.

What is a String?

A String is a collection of characters or text.

Strings are written inside quotes. 

name = "Harshika"

message = 'Hello World'

1. Creating a String

We can use single quotes or double quotes. 

name = "Harshika"

course = 'Cybersecurity'

print(name)
print(course)

2. String Indexing

Each character in a string has an index number. Index starts from 0. 

name = "Python"

print(name[0])
print(name[1])
print(name[2])

Output:

P
y
t

3. Negative Indexing

Negative indexing starts from the end of the string. 

name = "Python"

print(name[-1])
print(name[-2])

Output:

n
o

4. String Slicing ✂️

Slicing is used to get a part of a string. 

name = "Python"

print(name[0:3])

Output:

Pyt

Here 0 is the starting index and 3 is the ending position.

5. upper() and lower()

upper() converts text into uppercase.

lower() converts text into lowercase. 

name = "Harshika"

print(name.upper())
print(name.lower())

Output:

HARSHIKA
harshika

6. replace()

replace() replaces one part of a string with another. 

message = "I love Python"

new_message = message.replace("Python", "Cybersecurity")

print(new_message)

Output:

I love Cybersecurity

7. split()

split() breaks a string into a list. 

text = "Python Linux Networking"

words = text.split()

print(words)

Output:

['Python', 'Linux', 'Networking']

8. len()

len() tells us the number of characters in a string. 

name = "Harshika"

print(len(name))

Output:

8

9. String Formatting

We can use an f-string to combine variables with text. 

name = "Harshika"
course = "Cybersecurity"

print(f"My name is {name}")
print(f"I am studying {course}")

Output:

My name is Harshika
I am studying Cybersecurity

10. Real-Life Cybersecurity Example 🔐

Strings are commonly used to store usernames, IP addresses, URLs and log messages. 

username = "admin"
ip_address = "192.168.1.10"

print("Username:", username)
print("IP Address:", ip_address)

Important Points ⭐

  • Strings store text.
  • Strings are written inside quotes.
  • Index starts from 0.
  • Negative index starts from the end.
  • upper() converts to uppercase.
  • lower() converts to lowercase.
  • replace() replaces text.
  • split() creates a list.
  • len() gives the length.
